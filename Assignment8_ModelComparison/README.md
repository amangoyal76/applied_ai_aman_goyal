Assignment 8: Model Comparison (Logistic Regression vs SVM vs Random Forest)

This assignment compares the performance of Logistic Regression, SVM, and Random Forest classifiers on a dataset.
Accuracy, Precision, Recall, and F1-score are calculated for each model.
ROC curves are plotted together for performance comparison.
5-fold cross-validation is applied to evaluate model stability and select the best performing model.
